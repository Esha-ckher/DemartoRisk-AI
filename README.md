# DermatoRisk AI 🧴

A web-based MVP for pre-usage skincare decision support, designed for adolescents and young adults (15–30) who rely on social media for skincare decisions.

## What it does
- Ingredient-level risk classification (Safe / Caution / High Risk)
- Social media claim analysis and reality check
- Trend vs Clinical dual view for each product
- Personalized insights based on skin type
- Real review pattern data from public sources

3. Pond's Light Moisturizer

## Data Sources
INCIDecoder · PubMed · Acne.org · Daraz · CosDNA · Folliculitis Scout · TikTok community analysis

## How to run
Download `DermatoRisk_AI_Final.html` and open in any browser. No installation, no API key, no internet required.

## Disclaimer
This tool is for decision-support only and does not replace professional dermatological consultation.
